## 🧩 핵심 기능 흐름

1️⃣ **이미지 등록**  
→ OCR로 텍스트 자동 추출

2️⃣ **AI 앤디의 문맥 분석**  
→ 자연어 문장을 일정 데이터로 구조화

3️⃣ **일정 생성 + 최적 시간대 추천**  
→ 사용자의 기존 일정과 충돌하지 않는 시간대 자동 제안

4️⃣ **Google Calendar 연동**  
→ SCANdy와 Google 일정이 자동 동기화되는 통합 캘린더
