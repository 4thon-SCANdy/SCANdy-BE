### [SCANdy] - Backend  
**4호선톤 3팀 | 일정 등록 서비스**

---

#### 📌 프로젝트 소개  
**SCANdy**는 *이미지 기반 일정 등록 웹서비스*입니다.  
이미지 속 텍스트를 인식하여 자동으로 일정을 생성하고,  
Google Calendar와 연동하여 관리할 수 있습니다.

---

#### 🛠 기술 스택  
- **Language:** Python  
- **Framework:** Django REST Framework (DRF)  
- **Server & Deployment:** Docker, Nginx, Gunicorn  
- **ETC:** Google Calendar API
